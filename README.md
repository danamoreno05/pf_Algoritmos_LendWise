# 3. Descripción del Proyecto

LendWise es un sistema desarrollado en Python que permite gestionar el préstamo de artículos entre usuarios.

El sistema permite:

- Registrar usuarios
- Registrar artículos
- Registrar préstamos
- Registrar devoluciones
- Generar certificados de devolución
- Generar facturas cuando un préstamo supera los 30 días

# 5. Reporte de visión

El sistema LendWise busca proporcionar una herramienta sencilla para gestionar préstamos de artículos entre usuarios, permitiendo llevar control del inventario, registrar préstamos y generar facturas automáticas cuando se incumple el tiempo de devolución.
