# Manual de Usuario

## Sistema LendWise

Este sistema permite gestionar el préstamo de artículos entre usuarios.

## Ejecutar el sistema

Para ejecutar el programa use el siguiente comando:

python main.py

## Menú del sistema

1 Registrar usuario  
2 Registrar ítem  
3 Registrar préstamo  
4 Registrar devolución  
5 Consultar artículos prestados  
6 Administrador  
7 Salir
